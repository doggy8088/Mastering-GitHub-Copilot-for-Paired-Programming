# 開始使用 Copilot for Azure 進行雲端部署

[學習目標](../../../09-Using-GitHub-Copilot-for-Azure-to-Deploy-to-Cloud)  •  [先決條件](../../../09-Using-GitHub-Copilot-for-Azure-to-Deploy-to-Cloud)  •  [資源](../../../09-Using-GitHub-Copilot-for-Azure-to-Deploy-to-Cloud)

透過 GitHub Copilot for Azure 學習雲端部署 —— 您通往高效雲端成功的終極指南。首先建立堅實的基礎以提升程式設計效率，然後輕鬆過渡到應用程式部署，利用 Azure 的強大延展性。最後，學習進階故障排除技術，以確保您的應用程式可靠且高效能。讓 Copilot 成為您值得信賴的助手，您將自信地建立、部署和管理頂級應用程式，在每個階段提升您的雲端專業知識。

* **適合誰**：開發人員和資訊技術專業人員
* **您將學到什麼**：透過三個關鍵階段獲得對 GitHub Copilot for Azure 的全面了解：學習、部署和故障排除
* **您將建立什麼**：您將自信地建構、部署和維護高品質的應用程式

<a name="Learn"/>

## 學習目標

在本次研討會中，您將：

* 精通 GitHub Copilot for Azure 的基本概念和最佳實務
* 在 Azure 上實現無縫整合和具延展性的應用程式
* 使用進階工具診斷和解決問題，確保可靠的效能

<a name="pre-req"/>

## 先決條件

* [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)：GitHub Copilot 是一個 AI 配對程式設計工具，可以幫助您更快、更智能地編寫程式碼。
* [.NET 安裝工具](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.vscode-dotnet-runtime)：此擴展為其他擴展 (如 C# 和 C# Dev Kit 擴展) 提供統一的方法，以安裝本地版本的 .NET 運行時和機器範圍的 .NET SDK 版本。這些擴展告訴 .NET 安裝工具何時需要在機器上安裝 .NET SDK，如果沒有已匹配的 SDK，我們會為他們安裝一個。用戶也可以通過閱讀下面的內容自行安裝 .NET SDK。
* [GitHub Copilot for Azure](https://marketplace.visualstudio.com/items?itemName=ms-azuretools.vscode-azure-github-copilot)：GitHub Copilot for Azure 是 @azure 擴展。它旨在幫助簡化 Azure 的開發過程。您可以在 Visual Studio Code 中向 @azure 提問有關 Azure 服務的問題或獲得與 Azure 及其開發相關的任務幫助。
* [Microsoft Azure 帳戶](https://azure.microsoft.com/pricing/purchase-options/azure-account)：開始在雲端、本地和邊緣環境中無縫建構、部署和管理應用程式，利用 Azure 可擴展且具成本效益的服務。試用 Azure 免費 30 天，無需預先承諾 —— 隨時取消。
