# 掌握 GitHub Copilot 以進行結對開發

這是一門包含 9 課的課程，教授您如何將 GitHub Copilot 作為 AI 結對開發資源的所有知識。

透過我們全面的課程《掌握 GitHub Copilot 以進行結對開發》，釋放協作程式設計的力量。這個前沿的程序無縫整合了通過 GitHub Copilot 提供的 AI 驅動的程式設計輔助，讓學生能夠與夥伴一起加速提升程式設計技能。在 10 小時的引人入勝的課程中，參與者將掌握基本的設置程序，利用 Visual Studio Code 和 GitHub Copilot Chat 進行實時協作。深入探索 GitHub Copilot 的自動補全、自訂功能和進階編程技術，同時擁抱 AI 驅動的算法。從錯誤處理到單元測試，這個課程旨在灌輸最佳實踐並提升程式碼質量。沉浸於一個變革性的學習體驗，將最新的 AI 技術與結對開發策略融合，為您在當今動態的軟件開發領域提供成功所需的工具。

## 🌱 開始使用

要開始使用，請務必按照說明將課程分支到您自己的 GitHub 帳戶中。這將允許您根據自己的步調修改程式碼並完成挑戰。

要使用 GitHub Copilot，您必須擁有有效的 GitHub Copilot 訂閱。

**在這裡免費註冊：[GitHub Copilot](https://gh.io/copilot)**

為了方便將來再次訪問此儲存庫，您也可以 [給這個 repo 加星 (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-113596-abartolo)。

以下是每課的連結 —— 隨意探索並深入您最感興趣的任何主題！
