# GitHub 簡介

本學習模組深入探討 GitHub 的基本面向，這是一個頂尖的 AI 驅動開發者平台，促進協作式軟體開發。針對新開發者、GitHub 新手及學生，本模組提供在 GitHub 儲存庫中的實作經驗，並提供對基本功能的全面概述。

人們每天都在使用 GitHub 來構建地球上最先進的技術。無論你是在視覺化數據還是建立新遊戲，GitHub 上有一整個社群和一系列工具可以幫助你做得更好。

</header>

- **這是為誰準備的**：新開發者、新的 GitHub 使用者和學生。
- **你將學到什麼**：我們將介紹儲存庫、分支、提交和拉取請求。
- **你將構建什麼**：我們將製作一個簡短的 Markdown 文件，你可以用作你的 [個人簡介 README](https://docs.github.com/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme)。
- **先決條件**：無。本課程是你在 GitHub 上的第一天的絕佳入門。
- **時間**：本課程需時少於一小時完成。

本模組將幫助你：

1. 確認 GitHub 的基本功能。
2. 學習儲存庫管理的最佳實踐。
3. 理解 GitHub 流程，包括分支、提交和拉取請求。
4. 通過檢視問題和討論來探索 GitHub 的協作功能。
5. 認識如何管理你的 GitHub 通知和訂閱。

[![start-course](https://user-images.githubusercontent.com/1221423/235727646-4a590299-ffe5-480d-8cd5-8194ea184546.svg)](https://github.com/new?template_owner=skills&template_name=introduction-to-github&owner=%40me&name=skills-introduction-to-github&description=My+clone+repository&visibility=public)

1. 右鍵點擊 **開始課程**，並在新標籤中打開該連結。
2. 在新標籤中，大部分提示將自動為你填寫。
   - 對於擁有者，選擇你的個人帳戶或一個組織來托管儲存庫。
   - 我們建議創建一個公共儲存庫，因為私人儲存庫會 [使用 Actions 分鐘](https://docs.github.com/en/billing/managing-billing-for-github-actions/about-billing-for-github-actions?WT.mc_id=academic-113596-abartolo)。
   - 向下滾動並單擊表單底部的 **創建儲存庫** 按鈕。
3. 創建新儲存庫後，等待約 20 秒，然後刷新頁面。按照新儲存庫 README 中的逐步說明操作。
